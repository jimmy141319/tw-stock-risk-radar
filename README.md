# 台股每日風險監控雷達

這是一個可直接上傳 GitHub Pages 的靜態網站，用來每天監控台股或單一股票的風險。

## 核心判斷

危險組合：

> 成交量爆大量 + 融資增加 + 外資賣超 + 股東人數增加 + 千張大戶下降

這代表可能進入：

> 大戶／法人高檔換手，散戶承接

## 使用方式

1. 把整包檔案上傳到 GitHub repo。
2. GitHub Pages 指向 root。
3. 打開 `index.html`。
4. 每天收盤後輸入：
   - 成交量、20日均量
   - 漲跌幅
   - 外資、投信、自營商買賣超
   - 融資增減
   - TDCC 小散戶與千張大戶占比變化
   - KD / KDJ
5. 按「開始研判今日風險」。

## 自動抓資料

`scripts/fetch_twse.py` 可由 GitHub Actions 每天執行，抓取 TWSE 官方資料並產生 `data/latest.json`。

注意：TDCC 集保股權分散通常是週資料，散戶成交占比沒有官方精準即時欄位，只能透過集保、融資與法人參與率間接估算。

## 重要提醒

這是風險控管工具，不是買賣建議。
